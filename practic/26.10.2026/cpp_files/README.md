# Исходники

[К описанию проекта](../README.md) · [К скриншотам](../conclusion/)

Каждый `.cpp` - отдельная программа. Собирайте нужный файл по одному.

| Файл | Что делает |
| --- | --- |
| [1.cpp](1.cpp) | Выводит размеры восьми типов в байтах. |
| [2.cpp](2.cpp) | Принимает два целых числа и выводит результаты двух видов деления. При нулевом делителе завершает работу. |
| [3.cpp](3.cpp) | Преобразует `1000` в `char` и выводит полученное числовое значение. |
| [4.cpp](4.cpp) | Сравнивает `-1` и беззнаковую `1` до и после явного преобразования. |
| [5.cpp](5.cpp) | Читает число, затем строку с пробелами и выводит их. |
| [6.cpp](6.cpp) | Показывает разницу между `i++` и `++i`, затем сравнивает их в циклах. |
| [7.cpp](7.cpp) | Сравнивает `0.1 + 0.2` и `0.3` напрямую и с допуском. |
| [8.cpp](8.cpp) | Преобразует `3.14` в целое число. |

## Пример ввода

Для `2.cpp`:

```text
7 2
```

Результат:

```text
3
3.5
```

Для `5.cpp`:

```text
42
hello world
```

Результат:

```text
42
hello world
```

Остальные программы работают без ввода. Скриншоты находятся в папке [`conclusion`](../conclusion/).
