## Запуск

Нужен компилятор C++, например GCC или MSVC. Каждый файл собирается отдельно.

Пример для GCC в PowerShell из папки проекта:

```powershell
g++ -std=c++17 cpp_files/2.cpp -o 2.exe
.\2.exe
```

Для другого задания замените номер файла. Во втором и пятом заданиях программа ожидает ввод с клавиатуры.

## Что показывают задания

Размеры типов зависят от платформы. Целочисленное деление отбрасывает дробную часть, а сужение типа может менять значение. При сравнении знаковых и беззнаковых чисел нужно учитывать преобразования типов. Дробные числа в задании 7 сравниваются с допуском `1e-9`.
