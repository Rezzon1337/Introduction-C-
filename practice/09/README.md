## Перегрузки

| Вызов | Функция |
|---|---|
| printValue(count), printValue(1) | printValue(int) |
| printValue(reading), printValue(1.0) | printValue(double) |
| printValue(running), printValue(true) | printValue(bool) |
| delivery::cost(count) | cost(int) |
| delivery::cost(count, rate) | cost(int, int) |

Перегрузка выбирается по типам и количеству аргументов. При стандартном тарифе передаётся один аргумент, при индивидуальном — два.

## Область видимости до переименования

| Объявление | Где доступно имя | Значение | Обращение |
|---|---|---|---|
| Уровень файла | После объявления, в том числе через :: при затенении | 100 | ::value |
| main() | В main() после объявления, кроме затенения во вложенном блоке | 20 | value после блока |
| Вложенный блок | Внутри блока после объявления | 5 | value внутри блока |

Ожидаемый порядок: 5, 20, 100. После переименования вывод не меняется.
Обычный count создаётся заново при каждом вызове, static сохраняет значение между вызовами. При новом запуске оба счётчика начинают с 0.
